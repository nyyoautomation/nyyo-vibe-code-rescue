What to do now

  1. Rotate first. For each real key, create a new one in the provider's dashboard (AWS, Stripe, OpenAI, GitHub...) and revoke the old one. Deleting the line from your code is not enough: anyone who copied it can still use it.
  2. Move secrets out of the code. Put them in environment variables or your host's secret settings (Vercel, Netlify, Supabase...). Keys used in browser code are public by design: call the API from a server function instead.
  3. Keep .env out of git. Add .env to .gitignore and commit only a .env.example with placeholders.
  4. "Git history" findings are keys that were removed from the files but are still in old commits. Rotating them is what matters; rewriting history is optional and should be done carefully.
  5. False positive? Test values and placeholders can match. Check each line; to silence a known one, add its fingerprint (in findings.csv) to a .gitleaksignore file in your project.
